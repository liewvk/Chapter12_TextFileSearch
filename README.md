# Chapter12_TextFileSearch

A small C++ project (CMake-based) that implements text file search functionality.

## Overview

This repository contains C++ source code for searching text within files. It is intended as an example/project for Chapter 12 of a tutorial or book.

## Requirements

- A C++17 compatible compiler (g++, clang++)
- CMake 3.10+

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Run

After building, run the produced executable (replace `textfilesearch` with the actual binary name if different):

```bash
./textfilesearch <search-term> <path-to-directory-or-file>
```
